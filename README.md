# Coinone Invite Guide

코인원 초대코드 `73KGQG5M` 비공식 가이드. 정적 HTML/CSS/JS, 최대 폭 720px.

## 배포
1. 이 폴더 안의 파일을 GitHub `coinone-invite-guide` 저장소 루트에 업로드합니다.
2. Vercel에서 저장소를 Import하고 Framework Preset `Other`로 배포합니다.
3. 배포 URL이 확정되면 `index.html`에 canonical, og:url, 검색엔진 소유권 인증 메타 태그를 추가하고 `sitemap.xml`을 만드세요.
4. 네이버 서치어드바이저에 등록하고 사이트맵을 제출하세요.

## 주의
